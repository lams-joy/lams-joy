# `QUEST LOG`

### `QUEST 01 // SCHOLARSHIP ADMINISTRATION`

Built serverless backend APIs for a scholarship administration system.

```text
Azure Functions
       +
Microsoft Entra ID
       +
Role-Based Access Control
       +
Azure Blob / Table Storage
```

The interesting part wasn't simply making endpoints.

It was learning how authentication, authorization, cloud services and backend logic fit together into a system people can actually use.

---

### `QUEST 02 // SOKOHUB`

A progressive web app concept for small retailers.

```text
GO + MYSQL + PWA

Problem:
Small retailers need simple ways to keep reliable business records.

Objective:
Build something practical without overcomplicating it.
```

---

### `QUEST 03 // SMART HOME ALARM`

Final-year project exploring face recognition on a Jetson Nano.

Hardware limitations meant the project didn't go exactly as planned.

That became part of the lesson.

```text
FAILED ATTEMPT
      ↓
DEBUG
      ↓
UNDERSTAND THE LIMITATION
      ↓
DOCUMENT
      ↓
TRY AGAIN
```

Not every project ends with a perfect demo.

Some end with a much better developer.

---

### `QUEST 04 // SAUTI YETU`

A reporting platform concept focused on anonymous reporting and safer access to support in Kenyan boarding schools.

A reminder that good technology isn't only about what can be built.

It is also about **who it helps and how safely it can be used.**
