## `about me`

I'm **Joy Lamka**, a software developer with a background in **Microprocessor Technology & Instrumentation**. I enjoy working where software meets hardware, cloud systems, and real-world problems.

My journey has taken me from university labs and embedded systems to ICT support, backend development, Azure, AWS, Linux, Go, and hands-on problem solving at Zone01 Kisumu.

I'm interested in more than collecting technologies. I want to understand systems, build useful things, work with good people, and keep growing into a developer who can move comfortably between ideas, code, and the people those ideas are meant to serve.

## `things i've built`

### Scholarship Administration Backend

Built serverless backend APIs for a scholarship administration system, including administrator authentication with Microsoft Entra ID and role-based access control.

**Azure Functions · Entra ID · Blob Storage · Table Storage · GitHub · Azure DevOps**

### Sokohub

A progressive web app concept for small retailers who need a simple way to keep useful business records without unnecessary complexity.

**Go · MySQL · PWA**

### Smart Home Alarm

A final-year project exploring face recognition and hardware-based security with a Jetson Nano. The hardware limitations made the project a particularly valuable lesson in debugging, constraints and documenting what doesn't work.

**Python · Jetson Nano · Embedded Systems**

### Sauti Yetu

A reporting platform concept focused on anonymous reporting and safer access to support in Kenyan boarding schools.

**Python · Flask · Web**
